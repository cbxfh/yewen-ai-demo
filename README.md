# 行业 AI 工具包 · 第五版

面向餐饮与美容美发门店的行业知识库网站。第五版新增独立管理员实时后台，可查看注册用户数、登录会话、资料量、消息量和每日 AI 调用量。

## 本地运行

要求 Node.js 20.6 或更高版本，不需要安装第三方依赖。

```powershell
npm start
```

打开 `http://127.0.0.1:3000`。

AI 工作台：

```text
http://127.0.0.1:3000/assistant.html
```

### 手机访问

手机与电脑连接同一个 Wi-Fi 后，将 `.env` 中的 `HOST` 改为 `0.0.0.0`，启动服务，再在手机浏览器打开电脑的局域网地址。例如：

```text
http://172.20.80.167:8084/
http://172.20.80.167:8084/assistant.html
```

API 配置仍然从电脑上的 `.runtime/ai-config.json` 读取，不需要也不允许在手机端重新填写密钥。局域网地址和端口可能随网络变化，可在电脑运行 `ipconfig` 查看当前 IPv4 地址。

当前电脑已准备 `HOST=0.0.0.0`、`PORT=8084` 的本地 `.env`。如果手机无法连接，请确认两台设备在同一 Wi-Fi，并在 Windows 防火墙中允许 Node.js 或 TCP 端口 `8084`。

## 管理员实时后台

后台地址为 `/admin`。管理员账号和普通用户账号完全独立。

首次初始化必须在运行网站的电脑本机打开：

```text
http://127.0.0.1:8084/admin
```

设置管理员用户名和至少 12 个字符的密码后，可从公网地址登录后台。管理员会话有效期为 12 小时，普通用户会话不能访问后台接口。

后台每 5 秒自动刷新，显示：

- 注册用户总数与今日新增。
- 有效登录会话数。
- 各账号保存的个人资料数和对话消息数。
- 今日 AI 调用量。
- 最近 7 天注册趋势和账号概览。

后台不会展示用户密码、API 密钥、个人资料正文或对话正文。云端部署首次初始化也可以使用环境变量 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD`。

开发模式：

```powershell
npm run dev
```

运行测试：

```powershell
npm test
```

## 接入 AI API

### 方式一：网页设置入口

1. 打开网站右上角的“API 设置”，或进入 AI 工作台后点击“API 设置”。
2. 填写兼容 Chat Completions 的 API 基础地址、模型 ID 和 API Key。
3. 点击“测试连接”，确认收到有效回复后即可开始对话。

该设置入口仅接受本机访问，密钥保存在服务端的 `.runtime/ai-config.json`，不会返回到浏览器，也不会提交到 Git。非本机 HTTP 地址会被拒绝；云端地址需要 HTTPS。

### 方式二：环境变量

1. 在项目根目录把 `.env.example` 复制为 `.env`。
2. 填写 API Key、基础地址和模型。
3. 重启服务。

```env
AI_API_KEY=你的服务端密钥
AI_BASE_URL=供应商提供的v1基础地址
AI_MODEL=供应商当前可用的模型ID
AI_MAX_TOKENS=1200
```

`AI_BASE_URL` 应指向兼容 `/chat/completions` 的 v1 基础地址。也可以直接填写完整的 `/chat/completions` 地址。
项目不在代码中预设供应商或模型；三项都填写后才会启用对话。环境变量配置优先于网页保存的本机配置。

常见兼容服务包括 DeepSeek、阿里云百炼兼容模式等。具体地址、模型名称和可用参数请以你实际开通服务的当前文档为准，或把服务商信息发给我，我再补齐配置。

密钥只由 Node 服务读取，不会返回给浏览器。不要把 `.env` 提交到 Git。

## 主要功能

- 2 个行业方向：餐饮、美容美发。
- 12 份平台原创管理示例，每份包含背景说明、执行步骤、检查项和边界提示。
- 行业、类型、关键词、收藏四种筛选方式。
- 独立 AI 助手页面，可切换“全部 / 餐饮 / 美业”回答范围。
- 用户名 + 密码注册登录，密码使用 scrypt 加盐哈希保存。
- HttpOnly 会话 Cookie，有效期 30 天。
- 每位用户的资料、对话记录和使用额度按独立 `user_id` 隔离。
- 网页 API 设置、连接测试、本机安全存储和环境变量兼容。
- 个人知识库支持导入 TXT、MD、Markdown、CSV、JSON、HTML，也支持直接粘贴文本。
- 个人资料保存到当前账号的服务端隔离存储；同一账号可在不同设备登录后读取。
- 对话时最多选择 6 份资料、发送 24,000 字摘录；可随时取消选择或删除资料。
- 正文采用中文三号字，约 16pt / 21.33px。
- 服务端 API 代理、请求校验、基础限流和错误处理。
- 响应式页面，支持桌面与移动端。

## 手机端支持

- 首页、资料库、资料详情、搜索、收藏和 AI 工作台均适配手机屏幕。
- 已覆盖 320、360、390、430px 常见手机宽度。
- AI 工作台使用动态视口和安全区适配，手机浏览器地址栏变化时输入框仍可用。
- 个人知识库在手机上支持导入文本文件、选择资料、预览和删除。
- 手机用户登录自己的账号后读取对应账号数据，不会覆盖电脑或其他账号的数据。
- 支持添加到手机主屏幕。

## 个人知识库边界

当前版本只解析文本类资料，不处理扫描版 PDF、图片或 Word 中的复杂排版。知识库和对话记录保存在服务器端 `.data` 目录，不进入 Git。AI 只读取已勾选资料在单次对话上下文中截取出的文本；资料内容会发送到你配置的模型供应商用于生成回答。

每位用户只能通过自己的登录会话访问对应账号的数据。当前用户名密码体系暂未提供邮箱找回密码功能，请妥善保存账号信息。

## 内容与安全边界

当前资料是用于验证网站结构的原创示例，不是正式监管文件、医学建议或法律意见。上线前需要结合你的正式资料、门店流程和所在地规范完成专业复核。

AI 回答被提示优先使用站内资料，并拒绝用权威口吻补造法规或医疗结论；但生成式 AI 仍可能出错，实际经营决策必须由负责人复核。
